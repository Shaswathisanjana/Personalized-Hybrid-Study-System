How to write tests
Function example: [{"args":[[1,2,3]],"expected":6}]. Standard input/output: [{"stdin":"3\n","expected":"1\n2\n3\n"}]. Omit expected for an exploratory run, which cannot count as a correct solution.
For LeetCode methods, add an adapter such as def solve(nums, target): return Solution().twoSum(nums, target). Expected results use exact JSON comparison; use an adapter if the problem accepts multiple valid answers.
